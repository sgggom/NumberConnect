# 排布工具：真实手指遮挡模拟 v7

入口：关卡排布工具 → 选中棋盘 → 试玩模式 → 选择拇指 / 食指（默认拇指），选择左手 / 右手（默认右手） → 展开“真实手指遮挡模拟”。

支持当前棋盘自动跑关、无手指对照、逐步回放（上一步、下一步、播放、暂停）和 JSON 导出。结果不写入关卡库、排布草稿或玩家存档。编辑器原有跑关算法不受影响。

## 独立决策算法

1. 从数字 1 开始，模拟手指停留在当前已连接球的中心。每次决策前重新计算该姿态遮挡。
2. 使用食指原 PNG 的 alpha，或与试玩共用的拇指变形画布 alpha；不会把透明矩形算作手指。球面积按圆内 49 点采样；中央数字区域按 3 × 3 点采样，至少 3 点 alpha ≥ 128 则认为数字不可读。
3. 可见、未被挡的数字进入记忆。界面不再提供记忆步数，实际运行只使用当步看到的数字。已成功连接的数字持续记住；不在开始前额外扫描完整棋盘。
4. 以当前按住位置为中心构建九宫格。中心、棋盘外/空格、非相邻、已连接、已试错排除位置始终为 0。其余位置从 0 开始：已看见或记住的下一数字 +1，隐藏数字 +0.5；中央数字区被挡则乘 0.5；与上一次成功连线同方向再 +0.2；若隐藏格到下一个显示数字的直线距离严格小于当前指尖到它的距离，再 +0.3。目标取当前编号之后最小的显示编号，必须此刻未被遮挡且看得见：仅记得它不算，不能跳过被挡目标改用更后面的显示数字。距离相等不加分。其他显示数字始终为 0。隐藏且已确认是下一数字时两项累加。优先选择正权重中的最高值；唯一最高时概率为 100%，并列最高时等概率随机抽选，其余位置选择概率为 0，但保留原始权重显示。首次连接没有方向加分，错误尝试不更新方向。所有位置权重为零时，强制观察一次并重新计算；观察后仍无候选才停止。
5. 选择之后，独立的游戏判定器使用 ConnectionProgress 与路径求解器判定，接受合法的替代隐藏路径。隐藏答案只供判定和事后统计，不能供决策器选择。
6. 每步记录决策前画面、遮挡比例、已知数字、九宫格各位置权重与概率、尝试位置和判定结果。回放显示九宫格原始权重，粉色边框为本次抽中的位置，悬停可查看排除原因与遮挡比例；最后一帧显示完成后的连线。导出保留未四舍五入的概率，界面显示一位小数可能有舍入误差。

## 输出解释

- 平均错误：模型策略每轮被判错的次数。
- 相比无手指的错误差：相同棋盘、最高权重优先、并列时独立随机抽选下，两组结果均值之差，允许为负；有限随机样本不保证每轮遮挡都增加错误。
- 下一位置被挡比例：每次决策时，判定器当前合法解中的下一位置中央区域被挡的比例。包含错误重试；这项只是事后指标，决策器不会看到下一位置。
- 平均球面积遮挡：按全部球面积采样比例取均值，再按尝试步骤取均值。
- 导出包括每轮完整轨迹、无手指对照、随机策略、记忆设置、当前关卡数据及像素几何信息。

## 范围与限制

这是基于真实渲染轮廓的行为模型，不是经真人样本校准的难度评分。当前采用直接可见数字 + 短期记忆 + 未知位置试错策略；观察仅在决策中解除手指遮挡，不播放抬手动画；不模拟多步逻辑推理、眼动、动作耗时或滑动中途的视觉信息。棋盘几何位置视为玩家已知，手指遮挡影响数字读取。

窗口大小、棋盘显示尺寸、0.5–1 倍手指大小和握持姿态会影响遮挡，因此结果依赖当前布局。每次跑关固定采样几何，窗口改变需要重新跑关。当前只模拟所选棋盘，没有批量跑完整关卡库。

代码：`occlusionSimulation.ts` 为独立核心；`handOcclusion.ts` 负责 alpha 采样；`OcclusionSimulationPanel.ts` 负责统计、回放和导出。拇指采样直接调用 `ThumbHand.rasterize()`，与试玩使用同一套关节、握持移动和偏移。


## 指尖九宫格与逐步执行

九宫格是独立浮层，以指尖（紫红十字）为中心跟随移动，不吸附棋盘。模拟时显示本次决策的九方向原始权重，粉框标记抽中的位置；普通试玩移动时按指尖九宫格覆盖的位置和当前真实手指遮挡计算权重；显示数字只有当前看见或已连接的数字可识别。可用“指尖九宫格”开关隐藏。

“手动下一步”每点击一次计算并尝试一次连线；“自动”每 800ms 继续一步，可暂停后手动继续。“结束逐步模拟”返回普通试玩。“批量统计”保留多轮统计和无手指对照，下面的回放按钮仅用于查看已生成记录。两种执行方式使用同一权重算法，每步优先最高权重，并列最高时重新随机抽选，不复用固定种子。批量统计固定运行 5 轮。


## 玩家水平与观察

侧栏新增玩家水平（默认 1 档），适用于自动、手动下一步及批量统计。每次决策先判定是否观察，再计算权重。

| 档位 | 常规观察概率 | 上一步错误后的观察概率 |
| --- | --- | --- |
| 1 | 0% | 50% |
| 2 | 25% | 75% |
| 3 | 50% | 100% |
| 4 | 75% | 100% |
| 5 | 100% | 100% |

错误后使用错误概率替代常规概率。无论是否刚发生错误，所有权重为零时必定观察一次并重算；若已经观察过仍无候选，则停止，不重复观察循环。当相邻未连接位置中，没有未遮挡、未试错排除且可尝试的隐藏格或下一个显示数字时，强制观察。观察只对当次决策生效：手指遮挡折扣被移除，被挡的显示数字和距离目标可以读取，但隐藏数字仍隐藏、已错误位置仍为零。实际手图与姿态不变，物理遮挡统计照常保留；步骤信息单独标记“已观察／未观察／强制观察”。


## 手指显示与左右手

默认拇指、右手、显示手指。显示开关只控制可见图片，不传入遮挡采样或决策算法；隐藏后仍按选定类型、大小和左右手计算遮挡。左手将手指纹理、拇指姿态和握持位置水平镜像；可见渲染与离屏采样共用同一变换。内部无手指模式只用于对照统计，不再作为手指类型选项。


## 裁切与可配置权重

左手模式的食指和拇指只在实际棋盘矩形内显示，裁切范围由 SVG 棋盘坐标换算到屏幕坐标，不包含上下留白。离屏遮挡采样使用相同裁切；右手保持原显示范围。

侧栏“权重配置”可调整下一数字加分（默认 1）、隐藏数字加分（0.5）、被遮挡倍率（0.5）、同方向加分（0.2）、靠近目标加分（0.3），并可恢复默认。加分必须为非负数，倍率范围 0–1。修改后普通试玩九宫格重新计算，已生成的模拟结果失效；新的自动、单步、批量模拟及对照使用当前配置，导出记录配置快照。模拟过程中配置暂不可编辑，结束后可以修改。
