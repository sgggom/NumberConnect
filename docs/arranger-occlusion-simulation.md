# 排布工具：真实手指遮挡模拟 v7

入口：关卡排布工具 → 选中棋盘 → 试玩模式 → 选择拇指 / 食指（默认拇指），选择左手 / 右手（默认右手） → 展开“真实手指遮挡模拟”。

支持当前棋盘自动跑关、无手指对照、逐步回放（上一步、下一步、播放、暂停）和 JSON 导出。结果不写入关卡库、排布草稿或玩家存档。编辑器原有跑关算法不受影响。

## 独立决策算法

1. 从数字 1 开始，模拟手指停留在当前已连接球的中心。每次决策前重新计算该姿态遮挡。
2. 使用食指原 PNG 的 alpha，或与试玩共用的拇指变形画布 alpha；不会把透明矩形算作手指。球面积按圆内 49 点采样；中央数字区域按 3 × 3 点采样，至少 3 点 alpha ≥ 128 则认为数字不可读。
3. 可见、未被挡的数字进入记忆。界面不再提供记忆步数，实际运行只使用当步看到的数字。已成功连接的数字持续记住；不在开始前额外扫描完整棋盘。
4. 以当前按住位置为中心构建九宫格。中心、棋盘外/空格、非相邻、已连接、已试错排除位置始终为 0。其余位置从 0 开始：已看见或记住的下一数字 +1，隐藏数字 +0.5；中央数字区被挡则乘 0.5；与上一次成功连线同方向再 +0.2；若隐藏格到下一个显示数字的直线距离严格小于当前指尖到它的距离，再 +0.3。目标取当前编号之后最小的显示编号，必须此刻未被遮挡且看得见：仅记得它不算，不能跳过被挡目标改用更后面的显示数字。距离相等不加分。其他显示数字始终为 0。隐藏且已确认是下一数字时两项累加。优先选择正权重中的最高值；唯一最高时概率为 100%，并列最高时等概率随机抽选，其余位置选择概率为 0，但保留原始权重显示。首次连接没有方向加分，错误尝试不更新方向。所有位置权重为零时，强制观察一次并重新计算；观察后仍无候选才停止。
5. 选择之后，独立的游戏判定器使用 ConnectionProgress 与路径求解器判定，接受合法的替代隐藏路径。隐藏答案只供判定和事后统计，不能供决策器选择。
6. 每步记录决策前画面、遮挡比例、已知数字、九宫格各位置权重与概率、尝试位置和判定结果。回放显示九宫格原始权重，粉色边框为本次抽中的位置，悬停可查看排除原因与遮挡比例；最后一帧显示完成后的连线。导出保留未四舍五入的概率，界面显示一位小数可能有舍入误差。

## 输出解释

- 平均错误：模型策略每轮被判错的次数。
- 相比无手指的错误差：相同棋盘、最高权重优先、并列时独立随机抽选下，两组结果均值之差，允许为负；有限随机样本不保证每轮遮挡都增加错误。
- 下一位置被挡比例：每次决策时，判定器当前合法解中的下一位置中央区域被挡的比例。包含错误重试；这项只是事后指标，决策器不会看到下一位置。
- 平均球面积遮挡：按全部球面积采样比例取均值，再按尝试步骤取均值。
- 导出包括每轮完整轨迹、无手指对照、随机策略、记忆设置、当前关卡数据及像素几何信息。

## 范围与限制

这是基于真实渲染轮廓的行为模型，不是经真人样本校准的难度评分。当前采用直接可见数字 + 短期记忆 + 未知位置试错策略；观察仅在决策中解除手指遮挡，不播放抬手动画；不模拟多步逻辑推理、眼动、动作耗时或滑动中途的视觉信息。棋盘几何位置视为玩家已知，手指遮挡影响数字读取。

窗口大小、棋盘显示尺寸、0.5–1 倍手指大小和握持姿态会影响遮挡，因此结果依赖当前布局。每次跑关固定采样几何，窗口改变需要重新跑关。当前只模拟所选棋盘，没有批量跑完整关卡库。

代码：`occlusionSimulation.ts` 为独立核心；`handOcclusion.ts` 负责 alpha 采样；`OcclusionSimulationPanel.ts` 负责统计、回放和导出。拇指采样直接调用 `ThumbHand.rasterize()`，与试玩使用同一套关节、握持移动和偏移。


## 指尖九宫格与逐步执行

九宫格是独立浮层，以指尖（紫红十字）为中心跟随移动，不吸附棋盘。模拟时显示本次决策的九方向原始权重，粉框标记抽中的位置；普通试玩移动时按指尖九宫格覆盖的位置和当前真实手指遮挡计算权重；显示数字只有当前看见或已连接的数字可识别。可用“指尖九宫格”开关隐藏。

“手动下一步”每点击一次计算并尝试一次连线；“自动”每 800ms 继续一步，可暂停后手动继续。“结束逐步模拟”返回普通试玩。“批量统计”保留多轮统计和无手指对照，下面的回放按钮仅用于查看已生成记录。两种执行方式使用同一权重算法，每步优先最高权重，并列最高时重新随机抽选，不复用固定种子。批量统计固定运行 5 轮。


## 玩家水平与观察

侧栏使用三个独立玩家参数，见下方 v8 配置说明。每次决策先判定是否观察，再计算权重并进行推理筛选。

错误后使用错误概率替代常规概率。无论是否刚发生错误，所有权重为零时必定观察一次并重算；若已经观察过仍无候选，则停止，不重复观察循环。错误后，当相邻未连接位置中，没有未遮挡、未试错排除且可尝试的隐藏格或下一个显示数字时，强制观察。观察只对当次决策生效：手指遮挡折扣被移除，被挡的显示数字和距离目标可以读取，但隐藏数字仍隐藏、已错误位置仍为零。实际手图与姿态不变，物理遮挡统计照常保留；步骤信息单独标记“已观察／未观察／强制观察”。


## 手指显示与左右手

默认拇指、右手、显示手指。显示开关只控制可见图片，不传入遮挡采样或决策算法；隐藏后仍按选定类型、大小和左右手计算遮挡。左手将手指纹理、拇指姿态和握持位置水平镜像；可见渲染与离屏采样共用同一变换。内部无手指模式只用于对照统计，不再作为手指类型选项。


## 裁切与可配置权重

左手模式的食指和拇指只在实际棋盘矩形内显示，裁切范围由 SVG 棋盘坐标换算到屏幕坐标，不包含上下留白。离屏遮挡采样使用相同裁切；右手保持原显示范围。

侧栏“权重配置”可调整下一数字加分（默认 1）、隐藏数字加分（0.5）、被遮挡倍率（0.5）、同方向加分（0.2）、靠近目标加分（0.3），并可恢复默认。加分必须为非负数，倍率范围 0–1。修改后普通试玩九宫格重新计算，已生成的模拟结果失效；新的自动、单步、批量模拟及对照使用当前配置，导出记录配置快照。模拟过程中配置暂不可编辑，结束后可以修改。

## 独立玩家参数（v8）

原五档玩家下拉框改为三个独立配置：推理强度（低 0 步、中 2 步、高 5 步）、平时观察概率（0–100%，默认 0%）、错误后观察概率（0–100%，默认 50%）。默认低推理保留原选点行为。自动、单步、批量及无手指对照共用配置，导出包含 config.player。

推理使用当前认知数字、棋盘邻接关系及已连接位置，不读取隐藏答案。中、高档排除预判中数字不匹配、步数不足以到达已知目标、剩余格被隔断或无路继续的候选，到达目标或预判深度即停止。若全部排除则恢复原候选；随后仍按最高权重选点，仅并列最高随机。没有跨步数字记忆时，遮挡的数字不参与推理；观察后才可读取，关卡隐藏数字不会揭露。原有两种强制观察规则仍生效。

数字判定被挡后，按球面积采样比例分档：不足 50% 时基础权重乘 0.75；达到 50% 时使用侧栏“遮挡≥50%倍率”（默认 0.5）。之后再加同方向、靠近目标加分。仅遮到球边缘但数字未被判定遮挡时不扣分；观察时取消遮挡扣分。

新增第四项“观察推理概率”（0–100%，默认 0%）。每步首先按此概率，基于松开前可读数字和正权重候选做一次中等强度预判；即使仅剩一个候选也检查，全部失败时不回退候选，而是必定观察。存在候选或未触发时沿用平时／错误后观察概率。随后重新计算认知、权重并按所选推理强度选点。自动、单步、批量与对照共用，帧记录 observationReasoning 表示是否执行及是否无候选。


## 当前配置批量计算

左侧“批量计算当前配置”按当前配置模式的全部分组、棋盘顺序执行，不限当前页。每个配置棋盘扩展为关卡库中同阵型、同路径的全部难度版本，按难度升序逐个模拟一轮；不扩展到其他配置模式。每个配置位置保留来源，重复ID仍保留对应配置关号和棋盘序号；同一位置的已选难度不会重复加入，缺失库数据保留失败任务。启动时读取已保存的手指、大小、左右手、玩家参数和权重，固定预览区域尺寸，按各棋盘行列数等比居中采样。窗口尺寸变化自动取消，避免混用几何尺寸。

输出配置关号、棋盘序号、配置棋盘ID、实际id、难度、九项指标及状态，可导出带 UTF-8 BOM 的 CSV。支持取消并导出已完成部分；失败棋盘保留错误说明，未通关结果明确标注，指标表示已模拟到的部分。

- 总数字数量：实际路径格数；隐藏数字数量：开局隐藏格数，首尾显示格不计。
- 空1必中：未连接的相邻隐藏格只有一个，且为当前合法完成路径的下一数字。
- 空1误导：相邻隐藏格只有一个且不是下一数字，该隐藏格未被挡，真正下一数字被挡。
- 2选1／2空位间隔2：恰有两个未遮挡的相邻隐藏格，到下一个显示数字之间分别有1／2个数字。5→8的间隔为2，即使8被手挡住仍是显示数字锚点。
- 多空位：至少三个未遮挡的相邻隐藏格。
- 卡点：触发强制松手观察的位置数，包括错误后无未遮挡候选、零权重和观察预推理无候选。
- 错误次数：所有实际错误尝试累加。

各局面使用本位置第一次尝试前的状态及松手前物理遮挡；同一连接位置重试不重复累计，卡点在该位置任一次触发均只算一次。局面列不是互斥分类。数字是否被挡仍使用与试玩一致的中心采样判定。下一数字真值只进入指标统计，不提供给玩家选点算法。


## 多线程批量跑关

当前配置批量计算使用持久 Worker 池，默认并发数为浏览器报告的逻辑核心数减一，取消原8线程上限；计算面板可手动设置1～128线程（0为自动），实际不超过关卡任务数。主线程负责读取关卡、进度和结果展示；Worker 使用 OffscreenCanvas 进行真实手指透明度采样，并在同一线程执行观察、推理、选点和连线判定。不会逐步往返主线程调用路径判定。

实时手指与线程采样共用拇指网格绘制、左右镜像、裁切和数字遮挡判定；画布统一使用适合像素读取的上下文，避免渲染后端造成边界采样差异。每个线程缓存图片以及最近4组几何配置的姿态采样，同路径不同难度可复用遮挡结果。Worker只返回统计汇总，不传输整关回放数据。

结果按配置和难度顺序插入表格、导出CSV，完成顺序不会改变输出顺序。取消、关闭或窗口尺寸变化会立即终止所有 Worker；已完成结果保留。完成后释放线程。不支持 Worker、OffscreenCanvas 或 ImageBitmap 时，回退到原单线程方式。进度显示线程数、运行数、失败数及耗时。


## 范围选择与多次平均

“计算配置”先打开范围面板，配置表支持主玩法／挑战／活动（拼豆）多选和全选；关卡范围按各表的配置关号筛选，支持全部、包含起止关的区间、清空；难度支持全选、库中所有难度及全部清除，未标注难度的引导棋盘按0筛选。清空、不合法区间或无匹配结果时不能开始。

每关模拟次数默认为1，允许1～1000次。每个棋盘难度版本的各轮从初始状态重新开始，独立随机，复用手指几何缓存。动态指标取所有已完成轮次的算术平均值（包括未通关轮次的已产生计数），总数字数和初始隐藏数不变；同时报告通关次数，避免将未通关平均值误解为完整通关统计。表格、CSV及参数展示统一保留最多两位小数，导出附配置表、模拟次数、通关次数。取消时不发布未跑够指定次数的棋盘平均值，已完整完成的棋盘结果保留。


范围选择面板同时提供手指设置（类型、左右手、0.5～1倍大小）、玩家能力（推理强度与三个观察概率）和五项权重参数。打开时复制当前模拟的持久化设置，可用“使用当前模拟配置”重新带入。面板编辑仅影响本次批量运行，不覆盖普通试玩设置；开始时把参数快照传给线程池和兼容单线程路径，运行中固定不变。结果面板显示本次参数摘要。空值或越界值禁用开始按钮。

## 批量历史记录

计算配置弹窗分为左右两列：左侧计算范围和参数，右侧历史记录；两列独立滚动，底部操作固定可见。历史按时间倒序展示范围、模拟次数、手指设置、玩家能力、具名权重、棋盘/视窗尺寸、关卡库标识及完成状态，可查看原始结果表、导出 CSV 或删除。

历史使用当前浏览器、当前站点的 IndexedDB 保存，运行参数与结果分表存储。每完成一个棋盘版本即将结果和进度一起写入事务，避免反复重写整个批次。刷新后可查看已经落盘的结果；未结束的任务标为未完成，取消保留完整完成的版本，不保存未跑够指定次数的局部均值，也不会自动续跑。删除一条历史时同时删除其全部结果。保存失败明确提示用户导出 CSV，不宣称保存成功。历史查看不会重新计算，也不会覆盖当前模拟参数。

历史列表提供“应用到当前列表”：读取已保存统计，按实际关卡 ID 匹配当前库，覆盖匹配关卡的模拟结果缓存，参数区标注历史时间、配置位置和模拟次数；未匹配或无统计的行跳过。应用不重新跑关，不修改配置顺序或模拟参数，未覆盖的关卡保留原结果。

## 计算 Excel

关卡列表上方的“计算 Excel”选择.xlsx 文件（只需关卡ID和关卡数据两列，兼容原关卡名/关卡JSON列，沿用首个工作表导入规则），读取全部有效关卡版本，不按当前配置列表或难度筛选。读取后可设置每关模拟次数、手指、玩家能力和权重，默认带入当前模拟配置。结果使用已有多线程计算、平均统计、CSV和历史记录功能；结果配置表列为文件名，配置关号列为原表行号。

Excel 导入写入独立临时关卡库，不改变当前活动库或排布配置；完成、取消或失败后释放临时数据，历史结果独立保留。即使当前未导入关卡库，也可使用“计算配置”查看 Excel 历史。

Worker 内关闭普通试玩使用的每8步定时让步，避免计时器等待降低吞吐；Worker进度消息最多每100毫秒一次，并始终报告最终次数。普通试玩和单线程兼容路径继续保留让步。每个关卡的重复次数在同一 Worker 顺序执行，因此任务数不足或尾部剩余任务较少时，不保证所有核心占满。
