# 动态难度开发规格

更新日期：2026-09-08。基础实现参考已部署提交 `4964d7887bb7ed23491c9bc590c002b1c627b243`；本文已纳入最新确认的“受挫满 3，下一整关减 1 档，释放时清零”开发规则。

**实现状态：Web 已接入受挫事件、待释放减压、整关减档、状态机展示及存档迁移，随本次版本发布；部署状态以 GitHub Pages 工作流为准。其余能力评价、引导、考察关、五局节奏及重开规则沿用原方案。** 难度评分曲线是实验参数，预计通过率是内部能力模型估计，不是实测关卡胜率；受挫直接降档，不再改变目标通过率。

## 1. 基本口径

- 一关包含多个阶段，每个阶段对应一张棋盘。五局节奏中的“一局”指一整关，不是一个阶段或一次重试。
- 玩家能力在每个阶段首次有效结果出现时立即更新，不等待累计 X 局统一调整。
- 配置表指定关卡顺序、阶段顺序、阵型／路径家族。开启动态难度后，在该家族的 1–10 档预制布局中选取，不生成新棋盘。
- 配置 ID 最后一段的档位是关闭动态难度时的默认档位。阶段身份仍使用配置中的原始 formationId，不能用换档后的 ID 创建新的能力评价记录。
- 阶段身份：`levelId:stage:configuredFormationId`。同一阶段换档、刷新、复活、重开不能重置首次评价标记。
- 玩家能力跨阶段、跨关共享；升降档历史按阶段位置分别保存。
- 能力按阶段首次结果评价；受挫按事件累计，并在整关成功完成时按本关累计错误数结算一次。两套评价不可混用。
- 受挫达到 3 后保持 3，锁定一次待释放减压并暂停累计；下一符合条件的新整关开始时消耗机会，整关所有阶段减 1 档，同时受挫清零并恢复累计。

## 2. 参数与符号

| 符号 | 含义 | 初始值／范围 |
|---|---|---|
| S | 玩家能力分 | 初始 4，范围 [0,12] |
| F | 当前累计受挫值 | 初始 0，整数 [0,3]；满 3 待释放，使用时清零 |
| pendingRelief | 待释放整关减压机会 | 初始 false，最多 1 次 |
| h | 本关减压档数 | 整关开始时锁定为 0 或 1 |
| E | 累计有效证据权重 | 初始 0，非负，不设固定封顶值 |
| s | 阶段位置 | 从 1 开始；超过 4 时沿用第 4 阶段参数 |
| d | 关卡库档位 | 整数 1–10 |
| R(s,d) | 阶段中该档位的难度评分 | 不是档位本身 |
| T | 目标通过率 | 仅取阶段基础目标，不加入受挫加成 |
| P | 预计通过率 | 根据玩家能力与实际难度评分计算 |
| L[s] | 上次完成同一阶段位置时保存的基线档位 | 初始 null，之后为 1–10 |
| b | 本阶段动态基线档位 | 自动选档并限制升降后的结果 |
| o | 五局节奏的阶段偏移 | −1、0 或 +1 |
| d0 | 本阶段初始实际档位 | 加入节奏与整关减压后锁定；考察关固定 5 |
| dr | 当前实际档位 | 初始为 d0，主动重开后可降低 |

统一使用 `exp(x)`，等价于 `e^x`；`ln(x)` 为自然对数。

```text
clamp(x, lo, hi) = min(max(x, lo), hi)
i = clamp(s - 1, 0, 3)  // 参数数组的下标
```

| 阶段位置 | 基础目标 t[s] | 能力证据权重 w[s] | 难度评分下限 a[s] | 上限 z[s] |
|---|---:|---:|---:|---:|
| 1 | 0.95 | 0.2 | 0 | 1.5 |
| 2 | 0.90 | 0.4 | 0.5 | 2.5 |
| 3 | 0.60 | 1.0 | 2 | 8 |
| 4 及以后 | 0.85 | 0.7 | 1.5 | 6 |

其他参数：逻辑曲线斜率 0.65，受挫触发阈值 3，整关减压强度 1 档，基线单次升降限制 1 档，学习率系数 0.85，学习率下限比例 0.4，衰减部分比例 0.6，证据衰减尺度 12。

## 3. 进入阶段：完整处理顺序

| 顺序 | 处理 | 结果 |
|---|---|---|
| 1 | 读取存档与关卡配置，处理引导数量 | 确定关卡、阶段、阵型／路径家族 |
| 2 | 判断模式与已有阶段锁 | 引导／关闭动态难度走固定布局；已锁定阶段恢复已有档位与标记 |
| 3 | 为新正式关分配五局节奏并锁定本关减压 | 若有待释放机会，锁定 h=1、消耗机会、F清零；否则 h=0。整关共用，考察关不消耗 |
| 4 | 读取目标通过率 T | T=t[s]，受挫不再影响此值 |
| 5 | 枚举十档，寻找最接近 T 的档位 | 得到理想档位 d* |
| 6 | 以同阶段位置的历史 L[s] 限制升降 | 得到动态基线 b |
| 7 | 应用考察关或五局节奏 | 考察关 d0=5；普通关先 d节奏=clamp(b+o,1,10)，再 d0=max(1,d节奏−h) |
| 8 | 锁定并保存阶段数据 | 保存基线、初始档位、评分、选择时能力／受挫、节奏位置和本关减压标记 |
| 9 | 从家族中加载对应档位的布局 | dr=临时重开档位（若有），否则 dr=d0 |
| 10 | 游玩并收集错误、辅助、首次交互、失败／完成 | 能力按阶段结算；受挫按事件和整关完成结算，见第 7 节 |

已有锁定阶段不重新选档，也不因为能力变化、日期变化或重开重新分配局数。刷新或重新进入时，若上一尝试已操作但没有结算，能力按失败补结算，受挫按未结算尝试放弃 +1 处理，再清空本次尝试的错误与辅助标记；详见第 8 节。

## 4. 自动选档公式

### 4.1 档位换算为难度评分

```text
R(s,d) = a[s] + (d - 1) / 9 × (z[s] - a[s])
```

例如第 3 阶段第 4 档：`2 + 3/9 × 6 = 4`。

当前正式关使用上述线性评分。底层支持每个家族单独传入 10 个不递减、有限且在 [0,12] 的评分，但当前主流程没有配置专属曲线。当前重开后的记录评分仍使用默认线性曲线；如未来接入专属曲线，重开记录也需同步使用相同评分表。

### 4.2 预计通过率

```text
P(S,R) = 1 / [1 + exp(0.65 × (R - S))]
```

能力等于难度评分时为 50%；能力越高，通过率越高。

### 4.3 目标通过率

```text
T = t[s]
```

**作用：** 目标通过率只用于内部动态基线选档。移除原受挫通过率加成；受挫满 3 后通过下一整关直接减 1 档实现保护，不同时运行两套保护。

### 4.4 枚举最接近目标的档位

```text
d* = argmin(d ∈ {1,...,10}) abs(P(S, R(s,d)) - T)
```

从 1 到 10 枚举，只在误差严格更小时替换最优项，因此误差相同选较低档。不要对连续难度值四舍五入来代替枚举。

用于诊断目标是否超出评分范围的反解公式：

```text
raw = S - ln(T / (1 - T)) / 0.65
bound = raw < R(s,1) 或 raw > R(s,10)
```

`raw` 不直接决定最终档位；`bound` 仅用于显示诊断。

### 4.5 限制动态基线升降

```text
L[s] 为 null：b = d*
否则：b = clamp(d*, max(1,L[s]-1), min(10,L[s]+1))
limited = (b != d*)
```

比较对象是上次完成的同一阶段位置，不是本关上一阶段。限制作用于动态基线，之后再叠加体验节奏；不能把叠加后的结果重新按同一个限制截断。

## 5. 五局体验节奏

当前五局为 `−1、0、0、0、+1`，具体阶段矩阵如下：

| 五局位置 q | 名称 | 阶段 1 | 阶段 2 | 阶段 3 | 阶段 4 及以后 |
|---|---|---:|---:|---:|---:|
| 1 | 轻松进入 | −1 | −1 | −1 | −1 |
| 2 | 常规 | 0 | 0 | 0 | 0 |
| 3 | 常规 | 0 | 0 | 0 | 0 |
| 4 | 常规 | 0 | 0 | 0 | 0 |
| 5 | 挑战高峰 | 0 | +1 | +1 | 0 |

```text
d节奏 = clamp(b + offset[q][s], 1, 10)
d0 = max(1, d节奏 - h)
R0 = R(s,d0)
P0 = P(S,R0)
```

作用：先把五局节奏结果限制在合法档位，再应用本关减压。h 在整关开始时锁定，同一关每个阶段均使用同一个值。即使某阶段本来已是第 1 档也仍然属于本次减压关，不延长或返还减压机会。

- 按本机当地日期计日，不是固定北京时间，也不是每次启动重置。
- 新正式关第一次分配节奏时：日期变化则当天计数 n=0；`q=n%5+1`，随后 `n=n+1`。
- 计数依据是“首次进入新的整关”，不是通关次数。跳到尚未进入的新正式关也会分配一次。
- 同一关的多个阶段、重开、复活、刷新都复用其位置；已完成关卡回放也不重复分配。
- 跨日续玩旧关保留旧分配，次日首次进入新关时才开始新的第 1 局。
- 引导、考察关、动态难度关闭时不新分配节奏。已经进入关卡后才使用手动调试，不回滚此前已分配的局数。
- 旧存档某关已有阶段锁但没有节奏信息时，该关继续沿用旧规则；下一新关接入。
- 第 5 局仅提高中段，且档位有上下限，所以不保证其绝对难度永远高于其他四局。
- 节奏配置调整后，已经锁定的阶段保持实际初始档位；未锁定阶段使用当前偏移矩阵。界面分别展示计划偏移与已锁定实际档位。

## 6. 引导与考察关

### 引导

`guideLevelCount` 默认 3，可选整数 1–10。旧设置缺失时取 3；越界整数截断到范围，小数或无效值回退 3。

源关卡库第 1–10 关为引导关。只进行设定数量，之后跳到源第 11 关，不重排 ID。默认经历第 1、2、3 关后，第 4 个游玩关卡实际 ID 为 11。

引导固定布局，不更新能力、证据、受挫，不占五局节奏。

### 考察

开启动态难度时，源第 11 关为考察关。所有尚未锁定阶段初始档位均为 5，不受自动选档或历史升降限制影响，不占五局节奏。

能力、证据仍逐阶段正常评价；受挫按第 7 节的事件与整关规则累计，但考察关不消耗待释放机会，留到下一新普通动态关；原地复活保持棋盘，主动重开仍临时减档。完成后历史基准记为 5。源第 12 关开始进入普通动态选档与五局节奏。已存在的阶段锁优先恢复，不强行修改旧棋盘。

## 7. 阶段结果：公式与结算顺序

### 7.1 能力结果分类（不决定受挫变化）

| outcome | 条件 | 能力结果 y |
|---|---|---:|
| clean | 无错误、未使用辅助、完成阶段 | 1 |
| normal | 有错误、未使用辅助、完成阶段 | 1 |
| assisted | 使用辅助后完成阶段 | 0 |
| fail | 阶段失败，或能力规则中按失败处理的主动放弃 | 0 |

水彩笔、油漆桶、复活计为辅助。失败事件优先记 fail；完成时先判断辅助，再判断错误。单次操作错误不是阶段失败。**不能再通过 outcome 映射旧的受挫增量；例如辅助完成只影响能力结果，不额外加一遍受挫。**

### 7.2 去重与作用域

1. 阶段 completed=true：不再评价阶段能力，已完成回放不累计受挫。
2. 同一次失败重复回调：不重复评价能力，也不重复累计受挫。
3. excluded=true：不训练能力、不累计受挫、不更新历史基线。
4. measured=true：只关闭能力证据；后续新的失败、复活和道具事件仍可以影响受挫，但 pendingRelief=true 时暂停累计。
5. 阶段完成不能提前结算“关卡错误次数”三档；仅在整关首次成功完成时执行一次。
6. “真实失败”和“已操作主动放弃”是互斥的受挫原因。后者按 +1，不再触发真实失败 +2；已经失败再点击重开不重复加分。

### 7.3 按实际难度计算能力变化

保存结算前 `S_before`、`E_before`，采用当前实际档位 dr 对应的评分：

```text
P_result = 1 / [1 + exp(0.65 × (R(s,dr) - S_before))]
learningRate = 0.85 × [0.4 + 0.6 × exp(-E_before / 12)]
effectiveWeight = measured ? 0 : w[s]
S_after = clamp(S_before + learningRate × effectiveWeight × (y - P_result), 0, 12)
delta = S_after - S_before
E_after = E_before + effectiveWeight
measured = true
```

必须使用结算前 E 计算学习率，然后再累加证据；不能先加本次权重。计算使用完整浮点精度，仅界面显示时保留小数。

学习率初始为 0.85，随证据积累趋近 0.34。证据按首次结果的阶段权重累加，成功和失败都增加；不是局数，也不是置信度。四阶段各评价一次共增加 2.3。

选择时保存的 `selection.p` 是选档快照。结算时重新计算 `P_result`，不能直接把快照当作结算概率。节奏偏移影响实际难度，所以会影响首次结果的预计通过率与能力修正；重开后有效权重为 0，不重复修正能力。

### 7.4 结果后的状态变更

完成（clean／normal／assisted）：

```text
completed = true
L[s] = baselineDifficulty（有五局节奏时）
       否则 selection.difficulty（考察关为 5）
```

**不保存五局偏移、整关受挫减压或重开降档后的档位作为历史基准。** 即使重开后才完成，仍保存该阶段原基线。辅助完成同样会更新基线历史。

失败：

```text
failureRecorded = true
attempt = attempt + 1
```

失败不更新 L[s]。当前 `attempt` 初始为 1，在每次有效失败后递增，并非严格的“点击重开次数”；结算记录写入失败前的 attempt。

所有有效评分记录追加到 history，保留最近 200 条；界面仅展示最近 5 条。完成当前阶段后进入下一阶段，最后阶段完成则进入整关结算。

### 7.5 新受挫事件表

| 触发时机 | 条件 | 受挫变化 |
|---|---|---:|
| 整关成功完成时 | 本关累计错误次数 ≤2 | −1 |
| 整关成功完成时 | 2＜本关累计错误次数 ≤4 | 0 |
| 整关成功完成时 | 本关累计错误次数 ＞4 | +1 |
| 真实失败时 | 生命耗尽等有效失败事件 | +2 |
| 复活成功时 | 失败后选择复活 | +1 |
| 道具成功生效时 | 每次成功使用道具 | +1 |
| 主动重开时 | 本次尚未操作 | 0 |
| 主动重开时 | 已操作且当前尝试尚未结算 | +1 |

开发口径：

- 原讨论表中的“错误次数＜4”修正为“错误次数＞4”，使三档互斥且覆盖全部非负错误次数。
- 本关错误数按整关统计：从首次进入到首次整关完成，包含所有阶段及重试中的实际错误。阶段切换、重开、复活和刷新不清空该计数。它与每次尝试的 errors 分开保存。
- 错误次数档位只在整关成功完成时结算一次，含使用辅助后完成；辅助完成不再另加受挫。道具和复活已经在动作成功时分别累计。
- 真实失败发生在整关内的阶段也立即 +2，不必等整关结束。重复回调不加；复活或重开后的新一次真实失败可以再加。
- 失败 +2 与其后成功复活 +1 是两个不同事件，可以相加，恰好触发阈值。
- 道具仅在成功生效后计数；点击按钮、取消、使用失败不计。复活只走复活事件，不再同时当作道具事件 +1。
- 未操作重开受挫为 0，即使现有能力规则把它作为首次 fail 评价。能力事件与受挫事件必须分开。
- 刷新／重入的未结算已操作尝试，沿用“放弃本次尝试”口径 +1，不叠加真实失败 +2；退出动作本身不加。
- 引导、调试、关闭动态难度的游玩、已完成回放不累计；考察关可累计，但不消耗机会。

### 7.6 累计到阈值：保持满值并等待释放

```text
若 pendingRelief = true：忽略后续所有受挫增减事件（但仍记录实际错误、道具、复活统计）
否则：
  新受挫值 = clamp(当前受挫值 + 本次事件变化, 0, 3)
  若新受挫值 = 3：pendingRelief = true
```

作用：累计满 3 后锁定一次减压机会，不再持续叠加，也不被之后成功完成的 −1 抵消。**此时受挫仍为 3，不立即清零。** 正常能力评价不受暂停累计影响。

### 7.7 下一整关释放并清零

下一尚未开始的普通动态关首次初始化时：

```text
若本关已有初始化记录：恢复本关减压档数，不重新消耗机会
否则若 pendingRelief = true：
  本关减压档数 h = 1
  pendingRelief = false
  当前受挫值 F = 0
否则：
  本关减压档数 h = 0
```

作用：消耗一次机会换取下一整关所有阶段减 1 档。减压标记、机会消耗和清零必须作为同一次持久化更新，防止刷新后重复领取或丢失机会。

- 下一整关指下一尚未开始、可采用动态难度的新关；同关下一阶段、原关重开、复活、旧关回放不消耗。
- 引导、固定第 5 档考察关、关闭动态难度的关卡不消耗，机会保留。已有阶段锁的整关也不在中途追加整关减压。
- h 锁定后整关不变。当前关内重新累计到 3，只生成留给再下一新关的机会，不把当前关追加为 −2。
- 释放时即清零并恢复累计；不等减压关完成才清零。
- 本关每个阶段无论阶段开始时 F 是多少，都沿用 h；第 1 档是最低档，截断后仍视为本次减压已使用。
- 机会、F 与 h 都跨刷新、退出和跨天保存；五局日期重置不会重置它们。

## 8. 重开、复活、退出与刷新

| 事件 | 结算与档位处理 |
|---|---|
| 主动 replay／设置中重新开始 | 能力仍执行首次结果规则；受挫未操作为 0、已操作未结算为 +1，已失败不再加。之后清空本次尝试标记并 dr=max(1,dr−1)，保留整关错误累计与 h |
| 连续未操作就 replay | 受挫始终 0 变化；首次能力规则独立处理，之后仅继续临时降档 |
| 当前已到第 1 档后 replay | 仍为第 1 档，重新开始，不返还本关减压机会 |
| 失败后原地复活 | 复活成功受挫 +1（待释放时暂停）；保留棋盘、档位、进度、h 和错误累计，标记辅助；复活后新失败允许重新结算 |
| 退出当前关 | 保存状态，退出本身不立即增加受挫 |
| 刷新／重新进入未完成阶段 | 恢复已有档位与 h；上一尝试已操作未结算则能力补 fail、受挫放弃 +1；不额外降档、不清空整关错误累计 |
| 重新进入未操作阶段 | 不因此增加受挫，不额外减档 |
| 回放已完成阶段 | 不重复评价、不累计受挫、不消耗机会，不重新分配五局位置 |
| 开始同关下一新阶段 | 不继承前一阶段临时降档；使用最新 S 和该阶段 L[s] 选档，再应用同关五局偏移及 h；不消耗待释放机会 |
| 开始下一新整关 | 分配节奏，初始化 h；如果使用待释放机会，则 F 清零，之后重新累计 |

不能通过更换难度变体重新获得首次评价资格。降档只改变实际棋盘，不更换阶段身份，也不重置原始基线。

## 9. 持久化结构

### 核心算法存档

基础实现键：`number-connect.stage-dda.v1`；旧 version：`first-independent-v1`。新受挫规则版本为 `whole-level-relief-v1`，加载旧存档时自动迁移。

| 层级 | 主要字段 | 用途 |
|---|---|---|
| 全局 | skill、stress、evidence | 能力、受挫、证据 |
| 全局（新增） | pendingRelief、stressRuleVersion | 待释放机会、受挫规则版本 |
| levelRelief[levelId]（新增） | reliefApplied、errorCount、completionStressSettled | 本关减压 0/1、整关错误累计、整关完成受挫是否已结算；记录存在表示本关已初始化 |
| 尝试／事件（新增） | attemptId、失败／放弃结算标记、已处理事件标识 | 区分 +2 真实失败和 +1 放弃；道具与复活按事件去重 |
| stressHistory[]（新增） | levelId、type、before、after、pending | 受挫事件日志，与阶段能力 history 分开；保留 200 条、页面显示最近 5 条。重复回调由失败／完成标记与道具生效闭包阻止，待释放时不重复记日志 |
| 全局 | lastDifficulties[4] | 同阶段位置的历史基线 |
| stages[key] | levelId、stage、formationId、key | 稳定阶段身份 |
| stages[key].selection | difficulty、rating、p、target、raw、desired、stress、skill、limited、bound | 初始实际档位及选档快照；difficulty 是节奏和整关减压后的初始档位 |
| stages[key] | baselineDifficulty | 五局偏移和整关减压前的基线；新版普通动态阶段应保存，旧阶段及考察关可缺失 |
| stages[key] | replayDifficulty | 主动重开后的当前档位，可缺失 |
| stages[key] | measured、completed、failureRecorded | 评价／完成／失败去重标记 |
| stages[key] | started、assisted、excluded、errors、attempt | 当前尝试信息 |
| stages[key] | assessment、rhythm{day,position} | 考察标记及五局位置 |
| rhythm | day、next、levels[levelId]{day,position} | 当天分配计数和关卡节奏映射 |
| history[] | key、outcome、difficulty、rating、p、target、skillBefore、skillAfter、delta、stress、weight、evidenceUsed、attempt | 最近 200 条有效结果 |

锁定选档、玩家交互标记变化、每次受挫事件、整关减压领取、整关完成、重开、复活和退出时保存。新增整关错误累计不能复用会随重开清空的体验计数。旧字段缺失时保留旧阶段行为；明显损坏的核心存档回退默认状态，非法 history 项过滤；存储失败时当前实现继续以内存状态游玩。清除游戏数据会清除这些状态。

迁移建议（开发默认方案）：保留旧能力、证据、基线、已锁定棋盘和五局节奏；新受挫机制从 F=0、pendingRelief=false 开始，旧阶段所属整关初始化 h=0，不在中途领取。旧记录无法可靠还原整关错误数时，标记该旧关跳过一次完成错误档位结算，从下一新关完整统计。迁移只执行一次并保存版本；已完成回放不能被当作新关领取。

### 设置与展示统计

设置键 `number-connect.settings.v1` 保存动态难度开关（默认开）及引导数（默认 3）。关闭时按配置档位游玩，不评价能力与受挫，不新分配节奏；开关变化不即时更换当前已加载棋盘，后续加载阶段时采用新设置。

统计键 `number-connect.player-play-stats.v1` 保存不同普通拼图关卡 ID 集合，以及 errors、ads、revives 总数。含引导与当前关，重开不重复增加关卡数，不回填更新前缺失的统计。这些全局计数仅用于展示，不直接参与难度公式；新的受挫完成规则使用另外保存的本关 errorCount。

```text
总共关卡数 N = 去重后的已进入关卡 ID 数
平均每关错误数 = errors / N
平均广告观看次数 = ads / N
平均复活次数 = revives / N
```

N=0 时显示“—”，否则保留两位小数。目前普通拼图广告计数来自奖励复活路径，不能把它当作未来所有广告位的完整统计。

## 10. 示例与验收点

### 示例 A：失败复活触发，下一整关释放

| 事件 | F | 待释放 | 当前关 h | 说明 |
|---|---:|---|---:|---|
| 当前关开始 | 0 | 否 | 0 | 未领取减压 |
| 阶段真实失败 | 2 | 否 | 0 | +2 |
| 复活成功 | 3 | 是 | 0 | +1，锁定机会，暂停累计 |
| 后续使用道具／成功完成当前关 | 3 | 是 | 0 | 受挫冻结，实际错误等数据照常累计 |
| 下一新整关开始 | 0 | 否 | 1 | 领取一次整关减压并清零 |
| 减压关内使用道具 | 1 | 否 | 1 | 重新累计，不改变本关减压强度 |
| 减压关内再真实失败 | 3 | 是 | 1 | 为再下一新关准备机会，本关仍只 −1 |

假设减压关四阶段的五局节奏调整后档位分别为 [3,5,6,1]，实际初始档位为 [2,4,5,1]。每阶段能力结算使用实际档位评分，保存的历史基线不包含减压。

### 示例 B：能力评价与受挫独立

第 5 局、第 3 阶段，S=4、E=0、L[3]=null，本关已领取减压 h=1、F=0。

1. T=0.60，十档比较得到 b=3。
2. 中段节奏 +1 得第 4 档，再减 h=1 得初始第 3 档。
3. R=2+(3−1)/9×6≈3.333；P≈0.6067。
4. 首次失败：能力约为 4−0.85×0.6067≈3.4843，E=1；真实失败使 F=2。
5. 已失败后 replay 不再加受挫，当前实际档位降到 2；本阶段后续不再评价能力。
6. 阶段完成不按错误数减受挫；等整关完成后，按整关 errorCount 的三档规则结算一次。

开发验收至少覆盖：

1. 引导与考察规则保持；考察关可累计但不领取受挫机会。
2. 能力逐阶段首次评价不变；目标通过率不再加受挫保护系数。
3. 整关错误数边界 0、2、3、4、5 分别产生 −1、−1、0、0、+1；阶段完成不提前触发。
4. 真实失败 +2，复活成功 +1；重复事件去重；复活不能再当道具重复累计。
5. 道具成功生效才 +1；辅助完成不另加受挫；整关错误数完成规则照常处理。
6. 未操作重开受挫变化 0；已操作未结算放弃 +1；不得再叠加真实失败 +2。
7. F 达到 3 后锁定一次机会并暂停增减，保持 F=3；不是达到阈值当场清零。
8. 下一新整关领取 h=1 后清零；其所有阶段都减 1，第 1 档截断；重开、复活、刷新不重复领取。
9. 减压关内再次达阈值只能影响再下一新关；当前 h 不增加。
10. 同关跨阶段、跨天保留 h；待释放跨天保存；日期变化只影响五局分配。
11. 五局矩阵为 −1／0／0／0／中段+1，执行顺序为基线限制→五局偏移并截断→整关减压→重开减档。
12. 历史基线排除五局偏移、整关减压和重开减档；评分按实际难度计算。
13. 整关错误数跨重试和刷新累积，整关首次完成受挫只结算一次；旧存档按迁移口径处理。
14. 所有档位仍从同一家族加载，不因换档重新创建首次能力评价身份。
