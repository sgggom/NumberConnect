# 动态难度开发说明：中文参数公式版

> 2026-09-08 规则更新：本文保留旧版说明，受挫相关段落已过期。当前 Web 使用“事件累积满 3 → 冻结待释放 → 下一新整关所有阶段 −1 并清零”；目标通过率固定，不再加受挫保护。完整事件表、公式与边界以 [最新开发规格](dynamic-difficulty-development.md) 为准；简表见 [流程表](dynamic-difficulty-visuals.html)。

日期：2026-09-08。对应当前部署版本 `4964d78`，规则与《动态难度开发规格》一致。

本版将公式中的字母变量改为中文参数名称，每条公式下说明作用和使用时机。计算使用完整精度，只在界面显示时保留小数。预计通过率是模型估计，尚非实测通过率。

## 1. 参数名称和当前配置

| 参数名称 | 当前值／范围 | 含义 |
|---|---|---|
| 玩家能力分 | 初始 4，范围 0–12 | 玩家能力的长期估计 |
| 当前受挫值 | 初始 0，范围 0–3 | 近期是否需要减轻难度 |
| 累计有效证据权重 | 初始 0 | 各阶段首次有效结果的权重之和 |
| 最低档位／最高档位 | 1／10 | 关卡库档位边界 |
| 档位总数 | 10 | 每个阵型／路径家族的难度变体数量 |
| 通过率曲线系数 | 0.65 | 控制能力与难度差对预计通过率的影响 |
| 每点受挫保护量 | 0.08 | 每点受挫提高 8 个百分点的目标通过率 |
| 目标通过率下限／上限 | 0.05／0.97 | 目标通过率边界 |
| 基线最大单次升降档数 | 1 | 动态基线相对历史最多升降一档 |
| 初始学习率 | 0.85 | 初期能力修正幅度 |
| 学习率下限比例 | 0.4 | 长期保留的学习率比例 |
| 学习率衰减部分比例 | 0.6 | 随证据增多逐渐减小的部分 |
| 证据衰减尺度 | 12 | 控制学习率衰减速度 |
| 每次重开降档数 | 1 | 主动重开时临时降低一档 |
| 五局周期长度 | 5 | 体验节奏循环长度 |
| 引导关数量 | 默认 3，可选 1–10 | 完成后进入源关卡库第 11 关 |
| 考察关初始档位 | 5 | 首个正式关所有阶段的初始档位 |

| 阶段位置 | 阶段基础目标通过率 | 阶段证据权重 | 阶段难度评分下限 | 阶段难度评分上限 |
|---|---:|---:|---:|---:|
| 第 1 阶段 | 0.95 | 0.2 | 0 | 1.5 |
| 第 2 阶段 | 0.90 | 0.4 | 0.5 | 2.5 |
| 第 3 阶段 | 0.60 | 1.0 | 2 | 8 |
| 第 4 阶段及以后 | 0.85 | 0.7 | 1.5 | 6 |

“档位”是关卡库的 1–10 档；“难度评分”是代入通过率公式的数值，二者不能混用。

## 2. 数学函数约定

```text
限制范围(待处理数值, 下限, 上限)
  = 取较小值(取较大值(待处理数值, 下限), 上限)
```

**作用说明：** 将数值截断到指定范围。低于下限取下限，高于上限取上限，其余保持原值。它不负责四舍五入。

其他运算约定：`自然指数(数值)` 就是 `exp(数值)`，`自然对数(数值)` 就是 `ln(数值)`；`绝对值` 取差值的大小；`取余(被除数, 除数)` 取整数除法的余数。

## 3. 自动选档公式

### 3.1 将关卡库档位换算为难度评分

```text
候选档位难度评分
  = 阶段难度评分下限
    + (候选档位 − 最低档位) ÷ (档位总数 − 1)
      × (阶段难度评分上限 − 阶段难度评分下限)
```

**作用说明：** 将同一阶段的 10 个档位等间距映射到该阶段的难度评分区间，用于预计通过率计算。例如第 3 阶段第 4 档，难度评分为 `2 + (4−1)÷9×(8−2) = 4`。这不是直接把第 4 档当作难度评分 4，只是在该例中恰好相同。

### 3.2 计算候选档位预计通过率

```text
候选档位预计通过率
  = 1 ÷ [1 + 自然指数(
      通过率曲线系数 × (候选档位难度评分 − 当前玩家能力分)
    )]
```

**作用说明：** 估计玩家面对每个候选档位时的通过概率。能力等于难度评分时为 50%；能力更高时概率增加，难度更高时概率降低。选档时对十个档位分别计算。

### 3.3 计算本阶段目标通过率

```text
本阶段目标通过率
  = 限制范围(
      阶段基础目标通过率 + 每点受挫保护量 × 当前受挫值,
      目标通过率下限,
      目标通过率上限
    )
```

**作用说明：** 确定算法希望本阶段达到的通过概率。受挫越高，目标越高，选档会更偏向简单棋盘。例如第 3 阶段受挫为 2，目标为 `0.60 + 0.08×2 = 0.76`。

### 3.4 计算各档与目标的差距

```text
候选档位目标差距
  = 绝对值(候选档位预计通过率 − 本阶段目标通过率)
```

**作用说明：** 衡量每个档位与目标通过率的接近程度。越小越合适，不能只选择最高通过率或最高难度的档位。

```text
理想档位 = 十个候选档位中，目标差距最小的档位
```

**作用说明：** 从十档中完成初步选择。程序按 1 到 10 枚举，只有发现更小差距才替换；差距相同时保留较低档。这里必须比较十档，不用连续难度的四舍五入替代。

### 3.5 限制动态基线升降

```text
若没有上次完成同阶段位置的基线档位：
  本阶段动态基线档位 = 理想档位

否则：
  本阶段动态基线档位
    = 限制范围(
        理想档位,
        取较大值(最低档位, 上次完成同阶段位置的基线档位 − 基线最大单次升降档数),
        取较小值(最高档位, 上次完成同阶段位置的基线档位 + 基线最大单次升降档数)
      )
```

**作用说明：** 避免正常动态选档跳变过大。第 3 阶段与上次完成的第 3 阶段位置比较，不与本关第 2 阶段比较。第一次没有历史基线时不限制。该限制在五局节奏偏移之前执行。

```text
是否触发基线升降限制 = 本阶段动态基线档位 ≠ 理想档位
```

**作用说明：** 供界面或日志解释理想档位为何没有直接采用，不再额外改变档位。

## 4. 五局节奏公式

### 4.1 分配本关的五局位置

```text
本关五局位置 = 取余(当天已分配新正式关数量, 五局周期长度) + 1
```

**作用说明：** 依次产生第 1、2、3、4、5 局，然后循环回到第 1 局。分配发生在首次进入新的整关，不是完成一关之后，也不是每次阶段或重开时。

```text
分配后的当天新正式关数量 = 分配前的当天新正式关数量 + 1
```

**作用说明：** 为下一新关准备计数。必须先用旧数量计算本关位置，再增加数量；同一关各阶段复用已分配的位置。

本机当地日期变化后，首次为新关分配时将当天数量重置为 0。跨日续玩旧关保留旧分配，重开、复活和刷新都不推进。引导、考察关、关闭动态难度时不新分配；旧存档已锁定但无节奏信息的整关沿用旧规则。

### 4.2 查询本阶段体验偏移

```text
本阶段体验偏移 = 五局阶段偏移表[本关五局位置][当前阶段位置]
```

**作用说明：** 在适合玩家的动态基线之外，加入有规律的体验起伏。当前五局为“−1、0、0、0、+1”，但第 5 局只提高中间两个阶段，不能把 +1 应用到全关所有阶段。

| 本关五局位置 | 节奏 | 阶段 1 | 阶段 2 | 阶段 3 | 阶段 4 及以后 |
|---|---|---:|---:|---:|---:|
| 1 | 轻松进入 | −1 | −1 | −1 | −1 |
| 2 | 常规 | 0 | 0 | 0 | 0 |
| 3 | 常规 | 0 | 0 | 0 | 0 |
| 4 | 常规 | 0 | 0 | 0 | 0 |
| 5 | 挑战高峰 | 0 | +1 | +1 | 0 |

### 4.3 计算初始实际档位

```text
本阶段初始实际档位
  = 限制范围(
      本阶段动态基线档位 + 本阶段体验偏移,
      最低档位,
      最高档位
    )
```

**作用说明：** 得到这一阶段第一次实际加载的棋盘档位。例如动态基线为 4，第 5 局第 3 阶段偏移 +1，则初始实际档位为 5。结果只按 1–10 档截断，不再套一遍历史基线的 ±1 限制。

### 4.4 考察关覆盖规则

```text
考察关的本阶段初始实际档位 = 考察关初始档位 = 5
```

**作用说明：** 默认前三个引导关之后，用首个正式关考察玩家水平。本关各阶段固定从第 5 档开始，忽略自动选档和五局偏移，但首次结果仍正常评价。它对应源关卡库第 11 关，不占五局位置；之后恢复自动选档。

### 4.5 确定当前实际档位

```text
若已有重开临时档位：当前实际档位 = 重开临时档位
否则：当前实际档位 = 本阶段初始实际档位
```

**作用说明：** 决定此刻从关卡库加载哪一档。界面的“基线 → 初始 → 当前”分别对应动态基线、体验调整后的初始档位、重开后的实际档位。

## 5. 首次能力评价公式

### 5.1 将阶段结果转为独立完成结果值

```text
未使用辅助且完成：独立完成结果值 = 1
失败或使用辅助后完成：独立完成结果值 = 0
```

**作用说明：** 将玩家表现转成能力公式可使用的结果值。有错独立完成和无错独立完成都取 1；二者只在受挫更新中不同。水彩笔、油漆桶和复活属于辅助。

### 5.2 按实际棋盘重新计算结算通过率

```text
当前实际棋盘难度评分
  = 阶段难度评分下限
    + (当前实际档位 − 最低档位) ÷ (档位总数 − 1)
      × (阶段难度评分上限 − 阶段难度评分下限)
```

**作用说明：** 使用实际游玩的档位换算评分，不能拿配置表默认档位或节奏偏移前的基线代替。当前正式关采用这条线性评分公式。

```text
本次结算预计通过率
  = 1 ÷ [1 + 自然指数(
      通过率曲线系数 × (当前实际棋盘难度评分 − 结算前玩家能力分)
    )]
```

**作用说明：** 计算此次结果出现前的合理预期，用于判断表现高于还是低于预期。它应在结算时重新计算，不直接复用选档时存下的预计通过率快照。

### 5.3 计算学习率

```text
本次学习率
  = 初始学习率
    × [学习率下限比例
       + 学习率衰减部分比例
         × 自然指数(−结算前累计有效证据权重 ÷ 证据衰减尺度)]
```

**作用说明：** 控制一次结果对能力分的影响幅度。当前参数使学习率从 0.85 开始，逐渐接近 0.34；初期修正快，了解玩家后更稳定。必须先用结算前证据计算学习率，之后才增加本次证据。

### 5.4 确定本次有效证据权重

```text
本阶段尚未评价：本次有效证据权重 = 阶段证据权重
本阶段已经评价：本次有效证据权重 = 0
```

**作用说明：** 保证每个阶段仅使用首次有效结果修正能力。换档、重开、复活、刷新都不能重置“本阶段已评价”标记；否则同一棋盘会重复惩罚或奖励玩家。

### 5.5 计算能力变化并应用边界

```text
未截断能力变化
  = 本次学习率 × 本次有效证据权重
    × (独立完成结果值 − 本次结算预计通过率)
```

**作用说明：** 比较实际结果与预期。独立完成时结果值为 1，能力上升；失败或辅助完成时为 0，能力下降。原本预计越容易却失败，扣分越大；原本预计越难却完成，加分越大。已评价阶段权重为 0，因此不再加减能力。

```text
结算后玩家能力分
  = 限制范围(结算前玩家能力分 + 未截断能力变化, 0, 12)
```

**作用说明：** 将修正后的能力保持在合法范围。每个阶段首次结果出现后立即执行，不等待累计若干局。

```text
实际能力变化 = 结算后玩家能力分 − 结算前玩家能力分
```

**作用说明：** 用于结果记录和界面展示。能力接近 0 或 12 时，边界截断后的实际变化可能小于前面计算出的未截断变化，日志应记录实际值。

### 5.6 累加有效证据

```text
结算后累计有效证据权重
  = 结算前累计有效证据权重 + 本次有效证据权重
```

**作用说明：** 记录算法积累了多少有效观察，影响后续学习率。首次成功和首次失败都会增加对应阶段权重；不是通关数或置信度百分比。四阶段各首次评价一次，增加 `0.2 + 0.4 + 1.0 + 0.7 = 2.3`。

## 6. 受挫与历史基线更新

### 6.1 确定受挫变化

```text
无错误独立完成：本次受挫变化 = −1
有错误独立完成：本次受挫变化 = 0
失败或辅助完成：本次受挫变化 = +1
```

**作用说明：** 将近期体验与长期能力分开处理。即使同阶段已经评价过能力，新一次失败或完成仍可更新受挫。原地复活动作本身不直接加受挫，复活前的失败和之后的结果分别结算。

```text
结算后受挫值 = 限制范围(结算前受挫值 + 本次受挫变化, 0, 3)
```

**作用说明：** 将受挫保持在 0–3。新的受挫值参与后续阶段的目标通过率计算，不立即更换正在玩的棋盘。

### 6.2 完成阶段后保存历史基线

```text
存在本阶段动态基线档位：
  上次完成同阶段位置的基线档位 = 本阶段动态基线档位

没有独立保存动态基线的旧阶段或考察关：
  上次完成同阶段位置的基线档位 = 本阶段初始实际档位
```

**作用说明：** 为后续相同阶段位置的 ±1 档限制提供参考。必须排除五局体验偏移和重开临时降档，避免临时帮助或挑战逐渐改变长期选档基线。仅完成时更新，失败不更新；辅助完成也更新。

## 7. 主动重开与复活

```text
重开后的当前实际档位
  = 取较大值(最低档位, 重开前当前实际档位 − 每次重开降档数)
```

**作用说明：** 为卡关玩家逐次减压，最低到第 1 档。从当前实际档位减，而不是每次从动态基线重新减。重开后重新加载同一阵型／路径家族的低档布局。

执行前后顺序：

1. 已完成阶段或手动调试阶段，不执行临时降档。
2. 如果本阶段尚未评价，先把原棋盘按失败评价一次；未操作就主动重开也执行这一规则。
3. 已评价，但当前尝试已操作且尚未结算时，补记一次失败，只影响受挫。
4. 清空本次错误、辅助、交互和失败去重标记，保留已评价状态与初始档位。
5. 使用上面的公式降档并保存，再加载棋盘。

连续未操作就重开，第一次评价之后只继续减档，不额外累计失败和受挫。复活保留棋盘、档位和进度，标记辅助，不使用重开降档公式。刷新保留临时档位，也不额外降档。

## 8. 仅供诊断的公式

```text
目标对应的连续难度评分
  = 当前玩家能力分
    − 自然对数(本阶段目标通过率 ÷ (1 − 本阶段目标通过率))
      ÷ 通过率曲线系数
```

**作用说明：** 反推出理想情况下，要达到目标通过率需要多高的难度评分。用于解释目标是否超出关卡库范围；不直接决定最终档位，也不对它四舍五入选档。

```text
目标是否超出评分范围
  = 目标对应的连续难度评分 < 本阶段第 1 档难度评分
    或 目标对应的连续难度评分 > 本阶段第 10 档难度评分
```

**作用说明：** 告知程序和策划，现有十档可能无法准确满足目标通过率。标记只解释结果，不额外修改能力或档位。

## 9. 持久化展示统计公式

```text
总共关卡数 = 已进入普通拼图关卡编号集合的去重数量
```

**作用说明：** 统计更新后进入过的不同关卡，含引导和当前关；同一关切阶段或重开不重复计关。该数量不是当天五局节奏的计数。

```text
平均每关错误数 = 累计错误次数 ÷ 总共关卡数
```

**作用说明：** 展示平均每个已进入关卡累计产生多少错误，包括重试过程中的错误。仅展示，不参与能力公式。

```text
平均广告观看次数 = 累计广告观看次数 ÷ 总共关卡数
```

**作用说明：** 展示每个已进入关卡平均触发多少次已接入统计的广告观看。当前普通拼图来自奖励复活路径，未来增加其他广告位需要补接事件。

```text
平均复活次数 = 累计复活次数 ÷ 总共关卡数
```

**作用说明：** 展示每个已进入关卡平均复活次数。只用于观察体验，不直接影响能力评分；复活影响后续结果是否属于辅助完成。

三个平均值在总共关卡数为 0 时显示“—”，不得直接除以 0；其他情况显示两位小数。

## 10. 程序执行前必须检查的条件

- 引导关、动态难度关闭、手动调试不进行能力与受挫评价。
- 阶段已完成后，重复完成事件或回放不再结算；同一次失败的重复回调也不结算。
- 稳定阶段身份由“关卡编号＋阶段位置＋配置中的阵型编号”组成，不能使用换档后的变体编号重新建评价记录。
- 已锁定棋盘优先恢复；能力变化、日期变化、节奏配置更新不强行改掉当前已锁定的初始档位。
- 退出只保存状态；之后刷新或重新进入时，若上一尝试已操作但无结果，先补一次失败，不额外降档。
- 新阶段使用最新能力和受挫重新计算，临时重开降档不传给新阶段。
- 评分历史保存最近 200 条，界面展示最近 5 条。能力、受挫、证据、基线、阶段锁、五局分配和统计均需持久化。

具体存档字段、源码入口和完整验收案例见 [动态难度开发规格](dynamic-difficulty-development.md)。
